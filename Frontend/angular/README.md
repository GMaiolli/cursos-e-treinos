# 🅰️ Frontend — Angular

Este diretório é destinado aos projetos desenvolvidos em **Angular**, como parte do programa de treinamento técnico.

Cada desenvolvedor deverá criar seus próprios projetos seguindo os desafios propostos na trilha de aprendizagem.

Atenção: Todos os desafios deverão ser enviados APENAS para a sua branch!

---

## 🎯 Objetivo

- Aprender Angular na prática
- Desenvolver aplicações SPA
- Trabalhar arquitetura de frontend corporativo
- Consumir APIs backend

---

## 📁 Organização dos Projetos

Cada desafio deve ser criado em sua própria pasta:

```
angular/
├── desafio-01-componentes/
├── desafio-02-rotas/
├── desafio-03-api/
└── desafio-04-dashboard/
```

---

## 📌 Regras Gerais

- Criar projetos usando Angular CLI
- Utilizar TypeScript
- Não subir `node_modules`
- Manter código organizado

---

## 🧪 Testes

Sempre que possível, incluir:

- Testes unitários
- Testes de integração

---

## 🚀 Entrega

Cada desafio deve conter:

- Código-fonte
- README explicando:
  - Objetivo do projeto
  - Como executar
  - Tecnologias utilizadas
  - O que foi aprendido
