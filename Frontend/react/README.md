# ⚛️ Frontend — React

Este diretório é destinado aos projetos desenvolvidos em **React**, como parte do programa de treinamento técnico.

Cada desenvolvedor deverá criar seus próprios projetos seguindo os desafios propostos na trilha de aprendizagem.

Atenção: Todos os desafios deverão ser enviados APENAS para a sua branch!

---

## 🎯 Objetivo

- Desenvolver aplicações SPA modernas
- Trabalhar componentização
- Gerenciar estado
- Consumir APIs REST

---

## 📁 Organização dos Projetos

Cada desafio deve ser criado em sua própria pasta:

```
react/
├── desafio-01-componentes/
├── desafio-02-hooks/
├── desafio-03-api/
└── desafio-04-dashboard/
```

---

## 📌 Regras Gerais

- Utilizar Vite ou Create React App
- Preferencialmente TypeScript
- Não subir `node_modules`
- Código organizado e reutilizável

---

## 🧪 Testes

Sempre que possível, incluir:

- Testes unitários
- Testes de integração

---

## 🚀 Entrega

Cada desafio deve conter:

- Código-fonte
- README explicando:
  - Objetivo do projeto
  - Como executar
  - Tecnologias utilizadas
  - O que foi aprendido
