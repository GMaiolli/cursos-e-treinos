# ☕ Backend — Java

Este diretório é destinado aos projetos desenvolvidos em **Java**, como parte do programa de treinamento técnico.

Cada desenvolvedor deverá criar seus próprios projetos seguindo os desafios propostos na trilha de aprendizagem.

Atenção: Todos os desafios deverão ser enviados APENAS para a sua branch!

---

## 🎯 Objetivo

- Desenvolver conhecimento sólido em backend utilizando Java
- Aplicar boas práticas de arquitetura e código limpo
- Trabalhar padrões usados no mercado

---

## 📁 Organização dos Projetos

Cada desafio deve ser criado em sua própria pasta:

```
java/
├── desafio-01-fundamentos/
├── desafio-02-api-rest/
├── desafio-03-jpa/
└── desafio-04-seguranca/
```

---

## 📌 Regras Gerais

- Cada projeto deve conter seu próprio `README.md`
- O projeto deve compilar e executar
- Código limpo e organizado
- Commits claros e objetivos
- Não subir arquivos desnecessários (`target`, `.idea`, etc.)

---

## 🧪 Testes

Sempre que possível, incluir:

- Testes unitários
- Testes de integração

---

## 🚀 Entrega

Cada desafio deve conter:

- Código-fonte
- README explicando:
  - Objetivo do projeto
  - Como executar
  - Tecnologias utilizadas
  - O que foi aprendido
